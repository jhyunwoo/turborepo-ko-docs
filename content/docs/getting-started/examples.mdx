선호하는 도구로 예제를 부트스트랩하려면 `create-turbo`을 사용하세요.

<PackageManagerTabs>

<Tab value="pnpm">

```bash title="Terminal"
# 아래 나열된 예를 사용하십시오.pnpm dlx create-turbo@latest --example [example-name]

# 커뮤니티의 GitHub 저장소 사용pnpm dlx create-turbo@latest --example [github-url]
```

</Tab>

<Tab value="yarn">

```bash title="Terminal"
# 아래 나열된 예를 사용하십시오.yarn dlx create-turbo@latest --example [example-name]

# 커뮤니티의 GitHub 저장소 사용yarn dlx create-turbo@latest --example [github-url]
```

</Tab>

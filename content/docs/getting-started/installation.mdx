다음을 사용하여 잠시 후 Turborepo를 시작하십시오.

<PackageManagerTabs>

<Tab value="pnpm">


</Tab>

<Tab value="yarn">

</Tab>

스타터 저장소에는 다음이 포함됩니다.

- 배포 가능한 애플리케이션 2개
- 나머지 모노레포에서 사용할 세 개의 공유 라이브러리

스타터에 대한 자세한 내용은 [GitHub의 기본 스타터에 대한 README를 참조하세요](https://github.com/vercel/turborepo/tree/main/examples/basic)를 참조하세요. 도구 관련 관심 사항에 더 가까운 [예제를 사용](/docs/getting-started/examples)할 수도 있습니다.

## `turbo` 설치 중

`turbo`은 전역 **및 ** 저장소에 모두 설치할 수 있습니다. 저장소에서 작업하는 모든 개발자를 위해 빠르고 편리한 작업 흐름과 `turbo`의 안정적인 버전을 활용할 수 있도록 두 가지 방법을 모두 설치하는 것이 좋습니다.

### 전역 설치

`turbo`의 전역 설치는 로컬 워크플로우에 유연성과 속도를 제공합니다.

<PackageManagerTabs>

  <Tab value="pnpm">
  ```bash title="단말기"
 pnpm add turbo --global
 ```

  </Tab>

  <Tab value="yarn">
  ```bash title="단말기"
 yarn global add turbo
 ```

  </Tab>

  <Tab value="npm">
  ```bash title="단말기"
 npm install turbo --global
 ```

  </Tab>

  <Tab value="bun">
  ```bash title="단말기"
 bun install turbo --global
 ```

  </Tab>

</PackageManagerTabs>

전역적으로 설치되면 터미널에서 `turbo`을 통해 스크립트를 실행하고 일회성 명령을 빠르게 실행하여 저장소 내에서 사용할 수 있습니다. 예를 들면:

- `turbo build`: 저장소의 종속성 그래프에 따라 `build` 스크립트를 실행합니다.
- `turbo build --filter=docs --dry`: `docs` 패키지에 대한 `build` 작업의 개요를 빠르게 인쇄합니다(실행하지 않고).
- `turbo generate`: [Generators](/docs/guides/generating-code)를 실행하여 저장소에 새 코드를 추가하세요.
- `cd apps/docs && turbo build`: `docs` 패키지 및 해당 종속성에서 `build` 스크립트를 실행합니다. 자세한 내용은 [자동 패키지 범위 지정 섹션](/docs/crafting-your-repository/running-tasks#automatic-package-scoping)을 참조하세요.

<Callout type="info">
  `turbo`은 [`turbo run`](/docs/reference/run)의 별칭입니다. 예를 들어,
 `turbo build` 및 `turbo run build` 둘 다 `build` 작업을 실행합니다.
</Callout>

<Callout type="error" title="여러 전역 설치 방지">
  이전에 전역 `turbo`을 설치한 경우 동일한 패키지를 사용해야 합니다.
 예상치 못한 동작을 방지하려면 관리자를 기존 설치로 설정하세요. 당신은 할 수 있습니다
 이전에 [`turbo
 bin`](/docs/reference/bin)과 함께 사용했던 패키지 관리자를 빠르게 확인하세요.
</Callout>

#### CI에서 전역 `turbo` 사용

CI 파이프라인을 생성할 때 글로벌 `turbo`을 활용할 수도 있습니다. 자세한 내용은 [CI 구성](/docs/crafting-your-repository/constructing-ci#global-turbo-in-ci) 가이드를 참조하세요.

### 저장소 설치

저장소에서 다른 개발자와 공동 작업할 때 종속성 버전을 고정하는 것이 좋습니다. `turbo`을 저장소 루트에 `devDependency`으로 추가하여 이 작업을 수행할 수 있습니다.

<PackageManagerTabs>

  <Tab value="pnpm">
    ```bash title="단말기"
  pnpm add turbo --save-dev --ignore-workspace-root-check
  ```

  </Tab>

  <Tab value="yarn">
    ```bash title="단말기"
  yarn add turbo --dev --ignore-workspace-root-check
  ```

  </Tab>

  <Tab value="npm">
  ```bash title="단말기"
 npm install turbo --save-dev
 ```

  </Tab>

  <Tab value="bun">
  ```bash title="단말기"
 bun install turbo --dev
 ```

  </Tab>

  </PackageManagerTabs>

`turbo`의 전역 설치를 계속 사용하여 명령을 실행할 수 있습니다. 글로벌 `turbo`은 저장소의 로컬 버전(존재하는 경우)을 따릅니다.

이를 통해 두 설치의 장점을 모두 얻을 수 있습니다. 즉, 저장소의 모든 개발자가 일관되게 사용할 수 있도록 고정된 버전을 유지하면서 터미널에서 쉽게 명령을 실행할 수 있습니다.

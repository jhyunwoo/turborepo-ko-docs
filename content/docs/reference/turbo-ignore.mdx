패키지 또는 해당 종속성에 변경 사항이 있는지 확인하려면 `turbo`을 사용하세요. 이는 CI에서 작업을 빠르게 건너뛰는 데 유용할 수 있습니다.

```bash title="Terminal"
npx turbo-ignore [workspace] [flags...]
```

자세히 알아보려면 다음을 방문하세요.

- [작업 건너뛰기 소개 가이드](/docs/crafting-your-repository/constructing-ci#skipping-tasks-and-other-unnecessary-work)
- [작업 건너뛰기 고급 가이드](/docs/guides/skipping-tasks)
- [npm의 `turbo-ignore`에 대한 문서](https://www.npmjs.com/package/turbo-ignore)

## 터보 무시 버전 관리

`turbo-ignore`은 종속성을 저장소에 설치하기 전에 가장 자주 사용되므로 `turbo-ignore`을 실행할 때 사용 가능한 `turbo` 바이너리가 없습니다. 대신 `turbo-ignore`은 다음 전략에 따라 저장소에 사용할 올바른 버전을 검색합니다.

- 먼저 루트 `package.json#devDependencies` 또는 `package.json#dependencies`에서 `turbo` 항목을 확인합니다. 해당 버전이 발견되면 해당 버전이 사용됩니다.
- `package.json`에 `entry`이 없으면 해당 스키마에 대해 `turbo.json`을 읽습니다. [`tasks` 키](/docs/reference/configuration#tasks)가 발견되면 `turbo@^2`을 사용하세요. Turborepo v1의 `pipeline`이 발견되면 `turbo@^1`을 사용합니다.

모노레포에 패키지를 나열합니다.

```bash title="Terminal"
turbo ls [package(s)] [flags]
```

전체 저장소로 범위가 지정되면 출력에는 패키지 관리자, 패키지 수, 모든 패키지 이름 및 디렉터리가 포함됩니다.

```bash title="Terminal"
# 저장소의 모든 패키지 나열turbo ls
```

하나 이상의 패키지로 범위가 지정되면 출력에는 패키지 이름, 디렉터리, 내부 종속성 및 모든 작업이 포함됩니다.

```bash title="Terminal"
# 두 개의 패키지만 나열turbo ls web @repo/ui [package(s)]
```

## 플래그

### `--affected`

현재 분기의 변경 사항에 영향을 받는 패키지만 자동으로 필터링합니다.

기본적으로 고려되는 변경 사항은 `main`과 `HEAD` 사이의 변경 사항입니다.

- `TURBO_SCM_BASE`을 설정하여 `main`을 기본 베이스로 재정의할 수 있습니다.
- `TURBO_SCM_HEAD`을 설정하여 `HEAD`을 기본 헤드로 재정의할 수 있습니다.

```bash title="Terminal"
TURBO_SCM_BASE=development turbo ls --affected
```

### `--output <format>` <ExperimentalBadge />

결과를 출력하기 위한 형식입니다. `json` 또는 `pretty`(기본값)

```bash title="Terminal"
turbo ls --output=json
```

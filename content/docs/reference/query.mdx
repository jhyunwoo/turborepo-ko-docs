모노레포에 대해 GraphQL 쿼리를 실행합니다.

```bash title="Terminal"
turbo query [query] [flags]
```

인수가 전달되지 않으면 명령은 GraphiQL 플레이그라운드를 열어 쿼리를 실행합니다.

```bash title="Terminal"
turbo query
```

쿼리 문자열이 전달되면 명령이 쿼리를 실행하고 결과를 출력합니다.

```bash title="Terminal"
turbo query "query { packages { items { name } } }"
```

파일 경로가 전달되면 명령은 파일을 읽고 쿼리를 실행합니다.

```bash title="Terminal"
turbo query query.gql
```

파일 글로브는 다양한 컨텍스트에서 포함하거나 제외할 파일을 구성하기 위해 Turborepo 전체에서 사용되며 `turbo`에서 사용할 파일을 구체적으로 정의할 수 있습니다.

## 글로브 패턴

| 무늬 | 설명 |
| ----------- | ---------------------------------------------------------------------------------------------------- |
| `*` | 디렉터리의 모든 파일과 일치 |
| `**` | 모든 파일과 하위 디렉터리를 재귀적으로 일치시킵니다. |
| `some-dir/` | `some-dir` 디렉토리와 해당 내용을 일치시키세요. |
| `some-dir` | `some-dir` 또는 `some-dir` 디렉터리와 해당 콘텐츠를 일치시키는 파일을 찾습니다. |
| `some-dir*` | 디렉터리 일치 시 콘텐츠를 포함하여 `some-dir`으로 시작하는 파일 및 디렉터리 일치 |
| `*.js` | 디렉터리의 모든 `.js` 파일과 일치 |
| `!` | 전체 glob을 무효화합니다(정의된 glob의 끝에 `/**`을 자동으로 적용). |

## 예

| 무늬 | 설명 |
| ------------------ | ------------------------------------------------------------------------------------------------- |
| `dist/**` | `dist` 디렉터리, 해당 콘텐츠 및 모든 하위 디렉터리의 모든 파일과 일치합니다. |
| `dist/` | `dist` 디렉토리와 해당 내용을 일치시키세요. |
| `dist` | `dist` 또는 `dist` 디렉터리, 해당 콘텐츠 및 모든 하위 디렉터리와 일치합니다. |
| `dist/some-dir/**` | `dist/some-dir` 디렉터리의 모든 파일과 현재 디렉터리의 모든 하위 디렉터리를 일치시킵니다. |
| `!dist` | `dist` 디렉토리와 해당 내용을 모두 무시합니다. |
| `dist*` | `dist`으로 시작하는 파일 및 디렉터리 일치 |
| `dist/*.js` | `dist` 디렉토리에 있는 모든 `.js` 파일과 일치합니다. |
| `!dist/*.js` | `dist` 디렉토리에 있는 모든 `.js` 파일을 무시합니다. |
| `dist/**/*.js` | `dist` 디렉터리와 그 하위 디렉터리에 있는 모든 `.js` 파일을 재귀적으로 일치시킵니다. |
| `../scripts/**` | 한 디렉터리까지, `scripts` 디렉터리의 모든 파일 및 하위 디렉터리와 일치 |

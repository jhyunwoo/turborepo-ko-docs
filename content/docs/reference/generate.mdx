새로운 앱과 패키지로 Turborepo를 확장하세요.

```bash title="Terminal"
turbo generate
```

- [`turbo generate run [generator-name]`](#run-generator-name): 저장소에 정의된 사용자 정의 생성기를 실행합니다.
- [`turbo generate workspace [options]`](#workspace): 기존 패키지를 복사하거나 처음부터 저장소에 새 패키지를 만듭니다.

맞춤 생성기 작성에 대한 자세한 내용과 실제 사용 사례를 보려면 ['코드 생성' 가이드](/docs/guides/generating-code)를 방문하세요.

<Callout type="info">
  `turbo gen`은 `turbo generate`의 별칭입니다. 또한 `run`은(는)
 기본 명령이므로 `turbo gen`은 `turbo generate run`과 동일합니다.
</Callout>

## `run [generator-name]`

저장소에 정의된 사용자 정의 생성기를 실행합니다.

```bash title="Terminal"
turbo gen run [generator-name]
```

### 플래그 옵션

#### `--args`

생성기의 프롬프트에 직접 전달하기 위한 응답입니다.

#### `--config <path>`

생성기 구성 파일.

기본값: `turbo/generators/config.js`

#### `--root <path>`

저장소의 루트

기본값: 루트가 `turbo.json`인 디렉터리

## `workspace`

새 작업공간을 만듭니다.

```bash title="Terminal"
turbo gen workspace [options]
```

### 플래그 옵션

#### `--name <name>`

`package.json` `name` 키에 사용할 새 작업 영역의 이름입니다. `name` 키는 리포지토리에 있는 패키지의 고유 식별자입니다.

#### `--empty`

빈 작업 공간을 만듭니다. 기본값은 `true`입니다.

#### `--copy <name>/<url>`

모노레포 내의 로컬 작업공간 이름 또는 분기 및/또는 하위 디렉터리가 있는 정규화된 GitHub URL입니다.

#### `--destination <path>`

새 작업공간을 생성해야 하는 위치입니다.

#### `--type <app/package>`

생성할 작업 영역 유형(`app` 또는 `package`)

#### `--root <path>`

저장소의 루트입니다. 기본값은 루트 `turbo.json`의 디렉터리입니다.

#### `--show-all-dependencies`

추가할 종속성을 선택할 때 작업공간 유형별로 종속성을 필터링하는 것을 방지합니다.

#### `--example-path <path>`, `-p <path>`

드문 경우지만 GitHub URL에 슬래시가 포함된 분기 이름(예: `bug/fix-1`)과 예제 경로(예: `foo/bar`)가 포함될 수 있습니다. 이 경우 예제의 경로를 별도로 지정해야 합니다.

[Turborepo 코드 생성기](/docs/reference/generate)의 유형 정의에 이 패키지를 사용하세요.

```ts title="./turbo/generators/my-generator.ts"
import type { PlopTypes } from "@turbo/gen"; // [!code highlight]

// [!코드 단어:PlopTypes]export default function generator(plop: PlopTypes.NodePlopAPI): void {
  // 생성기 만들기  plop.setGenerator("Generator name", {
    description: "Generator description",
    // 사용자로부터 정보를 수집합니다.    prompts: [
      ...
    ],
    // 프롬프트에 따라 작업 수행    actions: [
      ...
    ],
  });
}
```

자세한 내용은 [코드 생성 가이드](/docs/guides/generating-code)를 참조하세요.

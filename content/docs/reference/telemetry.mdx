```bash title="Terminal"
turbo telemetry [argument]
```

이 컴퓨터에 대한 원격 측정을 관리합니다.

<LinkToDocumentation href="/docs/telemetry">
  Turborepo의 원격 측정에 대해 자세히 알아보세요.
</LinkToDocumentation>

## 인수

### `status`

이 머신의 현재 원격 분석 상태를 검색합니다.

```bash title="Terminal"
turbo telemetry status
```

### `enable`

이 컴퓨터에 대한 원격 측정을 활성화합니다.

```bash title="Terminal"
turbo telemetry enable
```

### `disable`

이 컴퓨터에 대한 원격 측정을 비활성화합니다.

```bash title="Terminal"
turbo telemetry disable
```

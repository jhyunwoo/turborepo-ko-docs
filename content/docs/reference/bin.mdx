`turbo` 바이너리의 경로를 가져옵니다.

```bash title="Terminal"
turbo bin
```

[**global `turbo`**](/docs/getting-started/installation#global-installation)을 사용하는 경우 이는 전역 `turbo` 바이너리의 경로가 됩니다. `turbo`을 설치하는 데 사용한 패키지 관리자의 전역 디렉터리 경로가 표시될 것입니다.

[**로컬 `turbo`**](/docs/getting-started/installation#repository-installation)을 사용하는 경우 이는 로컬 `turbo` 바이너리의 경로가 됩니다. `turbo`이 저장소에 설치되면 `node_modules`의 경로일 가능성이 높습니다.

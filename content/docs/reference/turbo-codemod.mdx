Turborepo는 기능이 더 이상 사용되지 않을 때 Turborepo 코드베이스를 업그레이드하는 데 도움이 되는 codemod 변환 및 자동 마이그레이션 스크립트를 제공합니다.

Codemod는 코드베이스에서 프로그래밍 방식으로 실행되는 변환입니다. 이를 통해 반복적인 변경 사항을 수동으로 관리할 필요 없이 많은 양의 변경 사항을 적용할 수 있습니다.

## 사용법

먼저 패키지 관리자의 설치 명령을 실행했는지 확인하세요.

```bash title="Terminal"
npx @turbo/codemod [transform] [path] [--dry] [--print]
```

- `transform` - ​​변환 이름, 아래에서 사용 가능한 변환을 참조하세요.
- `path` - 변환할 파일 또는 디렉터리
- `--dry` - 테스트 실행(코드는 수정되지 않습니다)
- `--print` - 비교를 위해 변경된 출력을 인쇄합니다.

## Turborepo 버전 업그레이드

대부분의 경우 다음을 실행할 수 있습니다.

```bash title="Terminal"
npx @turbo/codemod migrate
```

업그레이드하는 데 필요한 모든 코드모드가 자동으로 실행됩니다.

### Turborepo 2.x

아래 코드 모드는 Turborepo의 두 번째 주요 버전에서 마이그레이션 경로에 사용됩니다.

<Accordions>

<Accordion title="업데이트 버전 스키마-json(2.7.5)" id="update-versioned-schema-json">

버전이 지정된 하위 도메인 형식을 사용하도록 `turbo.json` 파일의 `$schema` URL을 업데이트합니다. 이는 루트 및 작업공간 `turbo.json` 파일 모두에 적용됩니다.

```bash title="Terminal"
npx @turbo/codemod update-versioned-schema-json
```

**예**

```diff title="./turbo.json"
{
- "$schema": "https://turborepo.dev/schema.json",
+ "$schema": "https://v2-7-5.turborepo.dev/schema.json",
}
```

</Accordion>

<Accordion title="업데이트-스키마-json-url(2.0.0)" id="update-schema-json-url">

버전이 지정된 Schema.json URL을 v2로 업데이트합니다.

```bash title="Terminal"
npx @turbo/codemod update-schema-json-url
```

**예**

```diff title="./turbo.json"
{
- "$schema": "https://turborepo.dev/schema.v1.json",
+ "$schema": "https://turborepo.dev/schema.v2.json",
}
```

</Accordion>

<Accordion title="패키지 이름 추가(2.0.0)" id="add-package-names">

이름이 없는 패키지의 `package.json`에 이름을 추가합니다.

```bash title="Terminal"
npx @turbo/codemod add-package-names
```

**예**

```diff title="./packages/ui/package.json"
{
+ "name": "@repo/ui",
}
```

</Accordion>

<Accordion title="클린 글로브(2.0.0)" id="clean-globs">

`turbo`의 glob 처리 변경으로 인해 유효하지 않은 glob 패턴을 수정합니다.

```bash title="Terminal"
npx @turbo/codemod clean-globs
```

**예**

```diff title="./turbo.json"
{
  "tasks": {
    "build": {
      "outputs": [
        // 연속된 이중별 접기-         "**/**.ext", // [!code highlight]
+         "**.ext" // [!code highlight]
        // 파일 확장자에 이중 별표가 없는지 확인하세요.-         "**.ext", // [!code highlight]
+         "**/*.ext" // [!code highlight]
        // 디렉토리 이름의 적절한 확장-         "prefix**/", // [!code highlight]
+         "prefix*/**" // [!code highlight]
      ]
    }
  }
}
```

</Accordion>

<Accordion title="마이그레이션 도트 환경(2.0.0)" id="migrate-dot-env">

제거된 `dotEnv` 키에서 `.env` 파일을 `inputs`로 이동합니다.

```bash title="Terminal"
npx @turbo/codemod migrate-dot-env
```

**예**

```diff title="./turbo.json"
{
  "tasks": {
    "build": {
-       "dotEnv": [".env"], // [!code highlight]
      "inputs": [
        "dist/**",
+         ".env" // [!code highlight]
      ],
    }
  }
}
```

</Accordion>

<Accordion title="이름 바꾸기 출력 모드(2.0.0)" id="rename-output-mode">

`outputMode` 키의 이름을 `outputLogs`으로 바꿉니다.

```bash title="Terminal"
npx @turbo/codemod rename-output-mode
```

**예**

```diff title="./turbo.json"
{
  "tasks": {
    "build": {
-     "outputMode": "errors-only" // [!code highlight]
+     "outputLogs": "errors-only" // [!code highlight]
    }
  }
}
```

</Accordion>

<Accordion title="파이프라인 이름 바꾸기(2.0.0)" id="rename-pipeline">

`pipeline` 키의 이름을 `tasks`으로 바꿉니다.

```bash title="Terminal"
npx @turbo/codemod rename-pipeline
```

**예**

```diff title="./turbo.json"
{
- "pipeline": {
+ "tasks": {
    "build": {
      ...
    },
    "dev": {
      ...
    },
    "lint": {
      ...
    }
  }
}
```

</Accordion>

<Accordion title="안정화-UI (2.0.0)" id="stabilize-ui">

`turbo.json`의 `experimentalUI` 키 이름을 `ui`로 바꿉니다.

```bash title="Terminal"
npx @turbo/codemod stabilize-ui
```

**예**

```diff title="./turbo.json"
{
- "experimentalUI": true
+ "ui": true
}
```

</Accordion>

### Turborepo 1.x

아래 코드 모드는 Turborepo의 첫 번째 주요 버전에서 마이그레이션 경로에 사용됩니다.

<Accordions>
<Accordion title="안정화 환경 모드(1.10.0)" id="stabilize-env-mode">

`turbo.json`의 `experimentalGlobalPassThroughEnv`을 `globalPassThroughEnv`로, `experimentalPassThroughEnv`을 `passThroughEnv`으로 마이그레이션합니다.

```bash title="Terminal"
npx @turbo/codemod stabilize-env-mode
```

**예**

```diff title="./turbo.json"
{
  "$schema": "https://turborepo.dev/schema.json",
- "experimentalGlobalPassThroughEnv": ["CC"],
+ "globalPassThroughEnv": ["CC"],
  "pipeline": {
    "build": {
-     "experimentalPassThroughEnv": ["GOROOT"],
+     "passThroughEnv": ["GOROOT"],
    }
  }
}
```

</Accordion>
<Accordion title="변환 환경 리터럴을 와일드카드로(1.10.0)" id="transform-env-literals-to-wildcards">

내용이 모호한 기존 환경 변수 필드를 새 와일드카드 구문으로 업데이트합니다.

```bash title="Terminal"
npx @turbo/codemod transform-env-literals-to-wildcards
```

**예**

```diff title="./turbo.json"
{
  "$schema": "https://turborepo.dev/schema.json",
- "globalEnv": ["THIS_*_IS_LITERAL"],
- "globalPassThroughEnv": ["!LITERAL_LEADING_EXCLAMATION"],
+  "globalEnv": ["THIS_\\*_IS_LITERAL"],
+  "globalPassThroughEnv": ["\\!LITERAL_LEADING_EXCLAMATION"],
  "pipeline": {
    "build": {
-     "env": ["50_PERCENT_OFF*_HAS_SMALL_PRINT"],
-     "passThroughEnv": ["**BOLDED**"],
+     "env": ["50_PERCENT_OFF\\*_HAS_SMALL_PRINT"],
+     "passThroughEnv": ["\\*\\*BOLDED\\*\\*"],
    }
  }
}
```

</Accordion>
<Accordion title="기본 출력 설정(1.7.0)" id="set-default-outputs">

이전에 추론된 `dist/**` 및 `build/**`을 포함하도록 `turbo.json` 출력을 마이그레이션합니다.

```bash title="Terminal"
npx @turbo/codemod set-default-outputs
```

**예**

```diff title="turbo.json"
{
  "$schema": "https://turborepo.dev/schema.json",
  "globalDependencies": [".env"],
  "globalEnv": ["CI_ENV"],
  "pipeline": {
    "build": {
      "dependsOn": ["^build"],
      "env": ["API_BASE"],
      "outputs": [".next/**", "!.next/cache/**"]
    },
-   "lint": {
-     "outputs": []
-    },
+   "lint": {},
    "dev": {
      "cache": false,
      "persistent": true,
+     "outputs": ["dist/**", "build/**"]
    }
  }
}

```

</Accordion>

<Accordion title="마이그레이션 환경 변수 종속성(1.5.0)" id="migrate-env-var-dependencies">

`turbo.json`의 모든 환경 변수 종속성을 `dependsOn` 및 `globalDependencies`에서 `env` 및 `globalEnv`로 각각 마이그레이션합니다.

```bash title="Terminal"
npx @turbo/codemod migrate-env-var-dependencies
```

**예**

```diff title="./turbo.json"
// 이후,turbo.json{
  "$schema": "https://turborepo.dev/schema.json",
- "globalDependencies": [".env", "$CI_ENV"],
+ "globalDependencies": [".env"],
+ "globalEnv": ["CI_ENV"],
  "pipeline": {
    "build": {
-     "dependsOn": ["^build", "$API_BASE"],
+     "dependsOn": ["^build"],
+     "env": ["API_BASE"],
      "outputs": [".next/**", "!.next/cache/**"],
    },
    "lint": {},
    "dev": {
      "cache": false,
      "persistent": true
    }
  }
}
```

</Accordion>
<Accordion title="추가 패키지 관리자(1.1.0)" id="add-package-manager">
`packageManager` 키가 감지된 패키지 관리자(`yarn`, `npm`, `pnpm`) 및 버전(예: `yarn@1.22.17`)이 되도록 루트 `package.json`을 변환합니다. 이 키는 이제 [Node.js에서 지원](https://nodejs.org/dist/latest-v17.x/docs/api/packages.html#packagemanager)되었으며 Turborepo에서 더 빠른 패키지 관리자 감지를 위해 사용됩니다(파일 시스템에서만 추론하는 것과 비교).

```bash title="Terminal"
npx @turbo/codemod add-package-manager
```

**예**

```diff title="./package.json"
{
  "name": "turborepo-basic",
  "version": "0.0.0",
  "private": true,
+  "packageManager": "yarn@1.22.17",
  "workspaces": [
    "apps/*",
    "packages/*"
  ]
}
```

</Accordion>

<Accordion title="생성 터보 구성(1.1.0)" id="create-turbo-config">

`package.json`의 `"turbo"` 키를 기반으로 프로젝트 루트에 `turbo.json` 파일을 생성합니다.
`"turbo"` 키는 이후에 `package.json`에서 삭제됩니다.

```bash title="Terminal"
npx @turbo/codemod create-turbo-config
```

**예**

```diff title="./package.json"
-     ...
-   }
```


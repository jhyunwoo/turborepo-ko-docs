특정 환경 변수를 설정하면 Turborepo의 동작을 변경할 수 있습니다. 이는 서로 다른 환경과 머신에 맞는 구성을 만드는 데 유용할 수 있습니다.

시스템 환경 변수는 항상 `turbo` 명령에 직접 제공한 플래그 값에 의해 덮어써집니다.

## 작업의 환경 변수

Turborepo는 작업이 실행되는 동안 다음 환경 변수를 작업 내부에서 사용할 수 있게 합니다.

| 변수           | 설명                                                                                                                                          |
| -------------- | -------------------------------------------------------------------------------------------------------------------------------------------- |
| `TURBO_HASH`   | 현재 실행 중인 작업의 해시입니다.                                                                                                             |
| `TURBO_IS_TUI` | [TUI](/docs/reference/configuration#ui)를 사용할 때 이 변수는 `true`로 설정됩니다.                                                          |
| `TURBO_IS_MFE` | [microfrontends](/docs/guides/microfrontends)를 사용할 때 이 변수는 해당 애플리케이션의 `microfrontends.json`에 정의된 포트로 설정됩니다. |

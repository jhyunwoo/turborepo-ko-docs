## 플래그 구문

값이 필요한 옵션은 공백이 필요할 때 따옴표를 사용하여 등호와 함께 전달할 수 있습니다.

```bash title="Terminal"
--opt=value
--opt="value with a space"
--opt value
--opt "value with a space"
```

## 글로벌 플래그

### `--color`

비대화형 터미널에서도 강제로 색상을 사용합니다. 이는 색상 렌더링을 지원하는 GitHub Actions와 같은 CI 환경에서 색상 출력을 활성화하는 데 유용합니다.

### `--no-color`

대화형 터미널에서도 터미널 출력의 색상을 억제합니다.

### `--no-update-notifier`

업데이트 알림을 비활성화합니다. 이 알림은 CI 환경에서 실행될 때 자동으로 비활성화되지만 이 플래그를 통해 수동으로 비활성화할 수도 있습니다.

또는 [`TURBO_NO_UPDATE_NOTIFIER` 환경 변수](/docs/reference/system-environment-variables)를 사용하여 알림을 비활성화할 수 있습니다.

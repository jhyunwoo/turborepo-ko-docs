원격 캐시 공급자에 로그인합니다.

```bash title="Terminal"
turbo login
```

기본 공급자는 [Vercel](https://vercel.com/)입니다. 다른 공급자를 지정하려면 `--api` 옵션을 사용합니다.

## 플래그 옵션

### --api \<url>

원격 캐시 공급자의 API URL을 설정합니다.

```bash title="Terminal"
turbo login --api=https://acme.com/api
```

### --로그인 \<url>

토큰을 동적으로 생성해야 하는 로그인 요청의 URL을 설정합니다.

```bash title="Terminal"
turbo login --login=https://acme.com
```

### --sso-팀 \<팀>

팀 슬러그를 제공하여 SSO 지원 팀에 연결하세요.

```bash title="Terminal"
turbo login --sso-team=slug-for-team
```

### --수동

로그인 서비스에서 토큰을 요청하는 대신 수동으로 토큰을 입력하세요.

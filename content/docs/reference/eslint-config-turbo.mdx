[`eslint-config-turbo` 패키지](https://www.npmjs.com/package/eslint-config-turbo)는 Turborepo 해싱의 일부가 아닌 코드에서 사용되는 환경 변수를 찾는 데 도움이 됩니다. `turbo.json`에서 설명되지 않은 소스 코드에 사용된 환경 변수는 편집기에서 강조 표시되고 오류는 ESLint 출력으로 표시됩니다.

## 설치

ESLint 구성이 있는 위치에 `eslint-config-turbo`을 설치합니다.

<PackageManagerTabs>

  <Tab value="pnpm">

    ```bash title="단말기"
  pnpm add eslint-config-turbo --filter=@repo/eslint-config
  ```

  </Tab>

  <Tab value="yarn">

    ```bash title="단말기"
  yarn workspace @acme/eslint-config add eslint-config-turbo --dev
  ```

  </Tab>

  <Tab value="npm">

    ```bash title="단말기"
  npm install --save-dev eslint-config-turbo -w @acme/eslint-config
  ```

  </Tab>

  <Tab value="bun">

    ```bash title="단말기"
  cd packages/eslint-config && bun install eslint-config-turbo --dev
  ```

  </Tab>
</PackageManagerTabs>

## 사용법(플랫 구성 `eslint.config.js`)

```js title="./packages/eslint-config/base.js"
import turboConfig from "eslint-config-turbo/flat";

export default [
  ...turboConfig,
  // 기타 구성];
```

구성에서 사용 가능한 규칙을 구성할 수도 있습니다.

```js title="./packages/eslint-config/base.js"
import turboConfig from "eslint-config-turbo/flat";

export default [
  ...turboConfig,
  // 기타 구성  {
    rules: {
      "turbo/no-undeclared-env-vars": [
        "error",
        {
          allowList: ["^ENV_[A-Z]+$"],
        },
      ],
    },
  },
];
```

## 사용법(레거시 `eslintrc*`)

eslint 구성 파일의 확장 섹션에 `turbo`을 추가하세요. `eslint-config-` 접두사를 생략할 수 있습니다.

```json title="./packages/eslint-config/base.json"
{
  "extends": ["turbo"]
}
```

구성에서 사용 가능한 규칙을 구성할 수도 있습니다.

```json title="./packages/eslint-config/base.json"
{
  "plugins": ["turbo"],
  "rules": {
    "turbo/no-undeclared-env-vars": [
      "error",
      {
        "allowList": ["^ENV_[A-Z]+$"]
      }
    ]
  }
}
```

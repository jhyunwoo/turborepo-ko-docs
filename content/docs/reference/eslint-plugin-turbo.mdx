[`eslint-plugin-turbo` 패키지](https://www.npmjs.com/package/eslint-plugin-turbo)는 Turborepo 해싱의 일부가 아닌 코드에서 사용되는 환경 변수를 찾는 데 도움이 됩니다. `turbo.json`에서 설명되지 않은 소스 코드에 사용된 환경 변수는 편집기에서 강조 표시되고 오류는 ESLint 출력으로 표시됩니다.

## 설치

ESLint 구성이 있는 위치에 `eslint-plugin-turbo`을 설치합니다.

<PackageManagerTabs>

  <Tab value="pnpm">

    ```bash title="단말기"
  pnpm add eslint-plugin-turbo --filter=@repo/eslint-config
  ```

  </Tab>

  <Tab value="yarn">

    ```bash title="단말기"
  yarn workspace @acme/eslint-config add eslint-plugin-turbo --dev
  ```

  </Tab>

  <Tab value="npm">

    ```bash title="단말기"
  npm i --save-dev eslint-plugin-turbo -w @acme/eslint-config
  ```

  </Tab>

  <Tab value="bun">

    ```bash title="단말기"
  cd packages/eslint-config && bun install eslint-plugin-turbo --dev
  ```

  </Tab>
</PackageManagerTabs>

## 사용법(플랫 구성 `eslint.config.js`)

ESLint v9는 아래와 같은 Flat Config 형식을 사용합니다.

```js title="./packages/eslint-config/base.js"
import turbo from "eslint-plugin-turbo";

export default [turbo.configs["flat/recommended"]];
```

그렇지 않으면 규칙 섹션에서 사용하려는 규칙을 구성할 수 있습니다.

```js title="./packages/eslint-config/base.js"
import turbo from "eslint-plugin-turbo";

export default [
  {
    plugins: {
      turbo,
    },
    rules: {
      "turbo/no-undeclared-env-vars": "error",
    },
  },
];
```

## 예(플랫 구성 `eslint.config.js`)

```js title="./packages/eslint-config/base.js"
import turbo from "eslint-plugin-turbo";

export default [
  {
    plugins: {
      turbo,
    },
    rules: {
      "turbo/no-undeclared-env-vars": [
        "error",
        {
          allowList: ["^ENV_[A-Z]+$"],
        },
      ],
    },
  },
];
```

## 사용법(레거시 `eslintrc*`)

`.eslintrc` 구성 파일의 플러그인 섹션에 `turbo`을 추가하세요. `eslint-plugin-` 접두사를 생략할 수 있습니다.

```json title="./packages/eslint-config/base.json"
{
  "plugins": ["turbo"]
}
```

그런 다음 규칙 섹션에서 사용하려는 규칙을 구성합니다.

```json title="./packages/eslint-config/base.json"
{
  "rules": {
    "turbo/no-undeclared-env-vars": "error"
  }
}
```

## 예(레거시 `eslintrc*`)

```json title="./packages/eslint-config/base.json"
{
  "plugins": ["turbo"],
  "rules": {
    "turbo/no-undeclared-env-vars": [
      "error",
      {
        "allowList": ["^ENV_[A-Z]+$"]
      }
    ]
  }
}
```

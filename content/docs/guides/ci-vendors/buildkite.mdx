다음 예에서는 [Buildkite](https://buildkite.com/)와 함께 Turborepo를 사용하는 방법을 보여줍니다.

특정 루트 `package.json`의 경우:

```json title="./package.json"
{
  "name": "my-turborepo",
  "scripts": {
    "build": "turbo run build",
    "test": "turbo run test"
  },
  "devDependencies": {
    "turbo": "latest"
  }
}
```

그리고 `turbo.json`:

```json title="./turbo.json"
{
  "$schema": "https://turborepo.dev/schema.json",
  "tasks": {
    "build": {
      "outputs": [".next/**", "!.next/cache/**"],
      "dependsOn": ["^build"]
    },
    "test": {
      "dependsOn": ["^build"]
    }
  }
}
```

다음 내용으로 저장소에 `.buildkite/pipeline.yml`이라는 파일을 만듭니다.

## 파이프라인 생성

Buildkite 대시보드에서 파이프라인을 생성하려면 먼저 리포지토리에서 파이프라인 정의를 업로드해야 합니다.

1. **파이프라인**을 선택하여 Buildkite 대시보드로 이동합니다.

2. **새 파이프라인**을 선택합니다.

3. 각 **이름** 및 **설명** 필드에 파이프라인의 세부 정보를 입력합니다.

4. **단계** 편집기에 저장소에서 정의를 업로드하는 단계가 있는지 확인합니다.

```yaml title=".buildkite/pipeline.yml"
steps:
  - label: ":pipeline:"
    command: buildkite-agent pipeline upload
```

5. **파이프라인 생성**을 선택한 다음 **새 빌드**를 클릭하고 **빌드 생성**을 선택합니다.

확인하려는 변경 사항이 있을 때마다 파이프라인을 실행하세요.

## 원격 캐싱

원격 캐싱을 사용하려면 공급자의 원격 캐시에 대한 팀과 토큰을 검색하세요. 이 예에서는 [Vercel 원격 캐시](https://vercel.com/docs/monorepos/remote-caching)를 사용합니다.

- `TURBO_TOKEN` - 원격 캐시에 액세스하기 위한 Bearer 토큰
- `TURBO_TEAM` - 모노레포가 속한 계정

Vercel 원격 캐싱을 사용하려면 몇 단계를 거쳐 이러한 변수의 값을 얻을 수 있습니다.

1. [Vercel 대시보드](https://vercel.com/account/tokens)에서 귀하의 계정에 대한 범위 지정 액세스 토큰을 생성하세요. 값을 안전한 곳에 복사하세요. 곧 필요할 것입니다.

  ![Vercel 액세스 토큰](/images/docs/vercel-create-token.png)

2. [팀 URL](https://vercel.com/d?to=%2F%5Bteam%5D%2F%7E%2Fsettings&title=Find+Team+URL)을 얻고 해당 값도 복사합니다. 두 값 모두 다음 단계에서 사용됩니다.

3. Buildkite 대시보드에서 각 값에 하나씩 두 개의 새로운 [Buildkite 비밀](https://buildkite.com/docs/pipelines/security/secrets/buildkite-secrets)을 생성합니다. `TURBO_TOKEN` 및 `TURBO_TEAM`으로 이름을 지정합니다.

4. `pipeline.yml`을 업데이트하여 그림과 같이 [Buildkite Secrets](https://github.com/buildkite-plugins/secrets-buildkite-plugin) 플러그인을 사용하여 `TURBO_TOKEN` 및 `TURBO_TEAM`을 환경 변수로 가져오고 적용합니다. (추가 비밀 관리 옵션은 Buildkite 문서의 [파이프라인 비밀 관리](https://buildkite.com/docs/pipelines/security/secrets/managing)를 참조하세요.)

  ```yaml title=".buildkite/pipeline.yml"
  steps:
   - label: ":test_tube: Test"
    command: |
     npm install
     npm test
    plugins:
     - secrets:
       variables:
        TURBO_TOKEN: TURBO_TOKEN
        TURBO_TEAM: TURBO_TEAM

   - label: ":hammer: Build"
    command: |
     npm install
     npm run build
    plugins:
     - secrets:
       variables:
        TURBO_TOKEN: TURBO_TOKEN
        TURBO_TEAM: TURBO_TEAM
  ```

  이러한 변경 사항을 저장소에 커밋하고 푸시하면 다음 파이프라인 실행 시 비밀이 적용되고 Vercel 원격 캐싱이 활성화됩니다.

## 일반 설정

CI에 대해 원격 캐싱을 활성화하려면:

1. CI에서 Turborepo에 대한 환경 변수를 설정하여 원격 캐시에 액세스합니다.
  | 변수 | 설명 |
  | ----------- | ----------- |
  | `TURBO_TOKEN` | 원격 캐시에 액세스하기 위한 Bearer 토큰 |
  | `TURBO_TEAM` | 저장소와 연결된 계정 이름입니다. <a href="https://vercel.com/docs/monorepos/remote-caching#vercel-remote-cache" rel="noreferrer noopener" target="_blank">Vercel 원격 캐시</a>를 사용하는 경우 이는 [팀의 슬러그](https://vercel.com/d?to=%2F%5Bteam%5D%2F%7E%2Fsettings&title=Get+team+slug). |
2. 리포지토리를 복제합니다.
3. 패키지 관리자를 통해 종속성을 설치합니다.
4. `turbo`을 통해 작업을 실행하세요.

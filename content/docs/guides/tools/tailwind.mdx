[Tailwind CSS](https://tailwindcss.com/)는 HTML을 종료하지 않고도 최신 웹사이트를 빠르게 구축할 수 있는 CSS 프레임워크입니다.

## 빠른 시작

템플릿을 사용하고 싶다면 이 가이드에서 [이 Tailwind CSS + Turborepo 템플릿](https://github.com/vercel/turborepo/tree/main/examples/with-tailwind)을 빌드하는 방법을 안내합니다.

<PackageManagerTabs>

<Tab value="pnpm">

```bash title="Terminal"
pnpm dlx create-turbo@latest -e with-tailwind
```

</Tab>

<Tab value="yarn">

```bash title="Terminal"
yarn dlx create-turbo@latest -e with-tailwind
```

</Tab>

<Tab value="npm">

```bash title="Terminal"
npx create-turbo@latest -e with-tailwind
```

</Tab>

<Tab value="bun">

```bash title="Terminal"
bunx create-turbo@latest -e with-tailwind
```

</Tab>
</PackageManagerTabs>

<Callout type="info">이 가이드는 Tailwind CSS v4용입니다.</Callout>

<Step>

### 애플리케이션에 Tailwind CSS 추가

[Tailwind CSS 가이드에 따라](https://tailwindcss.com/docs/installation/using-vite) 프런트엔드 프레임워크용 Tailwind CSS를 설정하세요.

완료되면 UI 패키지를 애플리케이션으로 가져오는 작업을 시작할 수 있습니다.

</Step>

<Step>

### 공유 Tailwind CSS 구성 패키지 만들기

먼저 4개의 파일로 [내부 패키지](https://turborepo.dev/docs/core-concepts/internal-packages)를 빌드합니다.

<Tabs items={["package.json", "shared-styles.css", "postcss.config.js (Optional)"]}>

<Tab value="package.json">

`package.json`은 Tailwind CSS를 설치하므로 파일 공유 스타일을 만들고 나머지 저장소에 대해 내보낼 수 있습니다.

```json title="./packages/tailwind-config/package.json"
{
  "name": "@repo/tailwind-config",
  "version": "0.0.0",
  "type": "module",
  "private": true,
  "exports": {
    ".": "./shared-styles.css",
    "./postcss": "./postcss.config.js"
  },
  "devDependencies": {
    "postcss": "^8.5.3",
    "tailwindcss": "^4.1.5"
  }
}
```

</Tab>

<Tab value="shared-styles.css">

이 `shared-styles.css` 파일은 저장소의 라이브러리 및 애플리케이션에 공유됩니다. 표시된 변수는 파일이 포함된 모든 곳에서 사용할 수 있습니다.

```css title="./packages/tailwind-config/shared-styles.css"
@import "tailwindcss";

@theme {
  --blue-1000: #2a8af6;
  --purple-1000: #a853ba;
  --red-1000: #e92a67;
}
```

</Tab>

<Tab value="postcss.config.js (Optional)">

프런트엔드에 PostCSS 구성 파일이 필요한 경우 공유할 파일을 생성할 수 있습니다.

```js title="./packages/tailwind-config/postcss.config.js"
export const postcssConfig = {
  plugins: {
    "@tailwindcss/postcss": {},
  },
};
```

</Tab>
</Tabs>

</Step>

<Step>

### UI 패키지 만들기

이제 애플리케이션에 공유할 구성요소를 구축할 수 있습니다.

전체 예시를 보려면 [Tailwind CSS 예시에서 `@repo/ui` 패키지의 소스 코드를 방문하세요](https://github.com/vercel/turborepo/tree/main/examples/with-tailwind/packages/ui). Tailwind CSS 설정에 필요한 파일은 다음과 같습니다.

<Tabs items={["package.json", "turbo.json", "styles.css"]}>

<Tab value="package.json">

`package.json`은 패키지에 대한 종속성을 설치하고, 개발 및 빌드 환경을 위한 스크립트를 설정하고, 패키지에 대한 내보내기를 표시합니다.

```json title="./packages/ui/package.json"
{
  "exports": {
    "./styles.css": "./dist/index.css",
    "./*": "./dist/*.js"
  },
  "scripts": {
    "build:styles": "tailwindcss -i ./src/styles.css -o ./dist/index.css",
    "build:components": "tsc",
    "dev:styles": "tailwindcss -i ./src/styles.css -o ./dist/index.css --watch",
    "dev:components": "tsc --watch"
  },
  "devDependencies": {
    "@repo/tailwind-config": "workspace:*",
    "@tailwindcss/cli": "^4.1.5",
    "@tailwindcss/postcss": "^4.1.5",
    "autoprefixer": "^10.4.20",
    "tailwindcss": "^4.1.5"
  }
}
```

<Callout type="info">
  위에는 Tailwind 설정과 관련된 코드만 포함했습니다. 전체
 package.json은
 [여기](https://github.com/vercel/turborepo/tree/main/examples/with-tailwind/packages/ui/package.json).
</Callout>

</Tab>

<Tab value="turbo.json">

구성 요소 및 스타일 시트를 병렬로 작성하기 위한 스크립트를 실행하는 `build` 및 `dev` 작업을 만듭니다.

```json title="./packages/ui/turbo.json"
{
  "extends": ["//"],
  "tasks": {
    "build": {
      "dependsOn": ["build:styles", "build:components"]
    },
    "build:styles": {
      "outputs": ["dist/**"]
    },
    "build:components": {
      "outputs": ["dist/**"]
    },
    "dev": {
      "with": ["dev:styles", "dev:components"]
    },
    "dev:styles": {
      "cache": false,
      "persistent": true
    },
    "dev:components": {
      "cache": false,
      "persistent": true
    }
  }
}
```

</Tab>

<Tab value="styles.css">

이 `styles.css`에는 공유 UI 라이브러리에 대한 구성 요소 수준 스타일이 포함되어 있습니다.

```css title="./packages/ui/src/styles.css"
/* UI 패키지의 구성 요소 수준 스타일 */
@import "tailwindcss" prefix(ui);
```

<Callout type="info">
  이 패키지에 사용되는 Tailwind 클래스에는 `ui:` 접두사가 붙어야 합니다.
 스타일 특정 문제.
</Callout>

</Tab>

</Tabs>

</Step>
<Step>

### 애플리케이션에서 UI 패키지 사용

생성한 패키지를 애플리케이션에 설치합니다.

<PackageManagerTabs>

<Tab value="pnpm">

```bash title="Terminal"
pnpm add @repo/ui @repo/tailwind-config --save-dev --filter=@repo/ui --filter=web
```

</Tab>

<Tab value="yarn">

```bash title="Terminal"
yarn workspace web add @repo/ui @repo/tailwind-config --dev
yarn workspace @repo/ui add @repo/ui @repo/tailwind-config --dev
```

</Tab>

<Tab value="npm">

```bash title="Terminal"
npm install @repo/ui @repo/tailwind-config --workspace=web --workspace=@repo/ui --save-dev
```

</Tab>

<Tab value="bun">

```bash title="Terminal"
cd apps/web && bun install @repo/ui @repo/tailwind-config --dev
cd packages/ui && bun install @repo/ui @repo/tailwind-config --dev
```

</Tab>
</PackageManagerTabs>

그런 다음 UI 패키지의 스타일이 애플리케이션에 반영되도록 애플리케이션에서 파일을 구성합니다.

<Tabs items={["globals.css", "layout.tsx", "postcss.config.js (Optional)"]}>

<Tab value="globals.css">

```css title="./apps/web/app/globals.css"
@import "tailwindcss";
@import "@repo/tailwind-config";
```

</Tab>

<Tab value="layout.tsx">

```tsx title="./apps/web/app/layout.tsx"
import "@repo/ui/styles.css";
import "./globals.css";
```

</Tab>

<Tab value="postcss.config.js (Optional)">

```js title="./apps/web/postcss.config.js"
import { postcssConfig } from "@repo/tailwind-config/postcss";

export default postcssConfig;
```

</Tab>

</Tabs>

</Step>

</Steps>

[Biome](https://biomejs.dev/)은 CI 및 개발자 시간을 절약해 주는 JavaScript, TypeScript, JSX, JSON용 빠른 포맷터입니다.

<CreateTurboCallout />

## Turborepo와 함께 Biome 사용하기

Biome은 **매우 빠르기** 때문에 Turborepo와 함께 사용되는 대부분의 도구에서 드문 예외입니다. 이러한 이유로 각 패키지에 별도의 스크립트를 생성하는 대신 [루트 작업](/docs/crafting-your-repository/configuring-tasks#registering-root-tasks)을 사용하는 것이 좋습니다.

<Callout type="info" title="캐싱 동작">
  프로젝트 루트에서 Biome을 사용하면 모든 항목에 대해 캐시 누락이 발생합니다.
 Biome 버전을 업그레이드하거나 구성을 변경할 때 작업을 수행합니다. 당신이 선호하는 경우
 이러한 상황에서는 캐시 적중률이 높을수록 더 적은 양의 캐시 적중률이 발생합니다.
 구성하더라도 다른 스크립트와 마찬가지로 별도의 스크립트에서 Biome을 계속 사용할 수 있습니다.
 우리 가이드의 권장 사항.
</Callout>

### 생물군계 초기화

먼저 저장소에 [설치 문서에 따라 Biome을 설정](https://biomejs.dev/guides/getting-started/)하세요. 그런 다음 저장소 루트에서 Biome을 사용하기 위한 스크립트를 생성할 수 있습니다.

```json title="./package.json"
{
  "scripts": {
    "format-and-lint": "biome check .",
    "format-and-lint:fix": "biome check . --write"
  }
}
```

### 루트 작업 만들기

실제로 Biome은 저장소의 반복 속도에 병목 현상이 발생하지 않을 것입니다. 이러한 이유로 [루트 작업](/docs/crafting-your-repository/configuring-tasks#registering-root-tasks)에서 Biome을 사용하면 저장소에서 관리할 구성이 줄어듭니다.

<Callout type="info">
  Biome이 저장소에서 작업으로 분할되어 더 빠를 수 있다고 생각하는 경우
 패키지를 사용하는 경우 자유롭게 그렇게 할 수 있습니다. 우리는 당신이 무엇을 실험해 볼 것을 권장합니다
 귀하의 사용 사례에 가장 적합합니다.
</Callout>

[루트 작업](/docs/crafting-your-repository/configuring-tasks#registering-root-tasks)을 생성하려면 스크립트를 Turborepo에 등록하세요.

```json title="./turbo.json"
{
  "tasks": {
    "//#format-and-lint": {},
    "//#format-and-lint:fix": {
      "cache": false
    }
  }
}
```

이제 `turbo run format-and-lint` 및 `turbo run format-and-lint:fix`을 사용하여 이러한 스크립트를 실행할 수 있습니다.

[Oxc](https://oxc.rs/)는 [oxlint](https://oxc.rs/docs/guide/usage/linter)(빠른 린터) 및 [oxfmt](https://oxc.rs/docs/guide/usage/formatter)(빠른 포맷터)를 포함하여 Rust로 작성된 고성능 JavaScript 및 TypeScript 도구 모음입니다.

<CreateTurboCallout />

## Turborepo에서 Oxc 도구 사용하기

[Biome](/docs/guides/tools/biome)과 유사하게 oxlint 및 oxfmt는 **매우 빠른** 도구입니다. 이러한 이유로 각 패키지에 별도의 스크립트를 생성하는 대신 [루트 작업](/docs/crafting-your-repository/configuring-tasks#registering-root-tasks)을 사용하는 것이 좋습니다.

<Callout type="info" title="캐싱 동작">
  프로젝트 루트에서 oxlint 또는 oxfmt를 사용하면 캐시 누락이 발생합니다.
 버전을 업그레이드하거나 구성을 변경할 때 모든 작업에 적용됩니다. 당신이 선호하는 경우
 이러한 상황에서는 캐시 적중률이 높을수록 더 적은 양의 캐시 적중률이 발생합니다.
 구성을 사용하더라도 이러한 도구를 다음과 같은 별도의 스크립트에서 실행할 수 있습니다.
 우리 가이드의 다른 권장 사항.
</Callout>

## 옥슬린트 설정

### 옥린트 설치

먼저 저장소에 oxlint를 설치합니다.

<PackageManagerTabs>

<Tab value="pnpm">

```bash title="Terminal"
pnpm add --save-dev oxlint
```

</Tab>

<Tab value="yarn">

```bash title="Terminal"
yarn add --dev oxlint
```

</Tab>

<Tab value="npm">

```bash title="Terminal"
npm install --save-dev oxlint
```

</Tab>

<Tab value="bun">

```bash title="Terminal"
bun add --dev oxlint
```

</Tab>
</PackageManagerTabs>

### 스크립트 만들기

저장소의 루트 `package.json`에 스크립트를 추가합니다.

```json title="./package.json"
{
  "scripts": {
    "lint": "oxlint .",
    "lint:fix": "oxlint --fix ."
  }
}
```

### 루트 작업 생성

스크립트를 [루트 작업](/docs/crafting-your-repository/configuring-tasks#registering-root-tasks)으로 Turborepo에 등록합니다.

```json title="./turbo.json"
{
  "tasks": {
    "//#lint": {},
    "//#lint:fix": {
      "cache": false
    }
  }
}
```

이제 `turbo run lint`을 실행하여 전체 저장소를 린트할 수 있습니다.

<Callout type="warn" title="유형 인식 린팅">
  Oxlint에서 [유형 인식 Linting 규칙](https://oxc.rs/docs/guide/usage/linter/config#type-aware-linting)을 활성화하는 경우 Linter가 올바르게 작동하려면 TypeScript 유형 정보가 필요합니다. 이는 유형 검사 전에 빌드해야 하는 모든 종속성(예: 모노레포의 [컴파일된 패키지](/docs/core-concepts/internal-packages#compiled-packages))도 Linting 전에 빌드해야 함을 의미합니다.

예를 들어 형식화 및 Linting을 실행하기 전에 컴파일된 패키지를 빌드하려면 다음을 수행하십시오.

```bash title="Terminal"
turbo run build --filter=./packages/* && turbo run lint
```

또는 `dependsOn: ["^build"]`을 사용하여 패키지별 Lint 작업으로 전환하여 Turborepo가 ​​주문을 처리하도록 할 수 있습니다.

</Callout>

## oxfmt 설정

oxfmt는 Prettier를 즉시 대체하도록 설계된 JavaScript 및 TypeScript용 빠른 코드 포맷터입니다.

<Callout type="warn" title="oxfmt는 실험적입니다">
  oxfmt는 현재 알파 버전이며 전체 기능이 oxfmt와 동일하지 않을 수 있습니다.
 더 예뻐요. [oxfmt를 확인하세요.
 문서](https://oxc.rs/docs/guide/usage/formatter)에서 최신 내용을 확인하세요.
 상태 및 지원되는 옵션.
</Callout>

### oxfmt 설치

oxfmt를 개발 종속성으로 설치합니다.

<PackageManagerTabs>

<Tab value="pnpm">

```bash title="Terminal"
pnpm add --save-dev oxfmt
```

</Tab>

<Tab value="yarn">

```bash title="Terminal"
yarn add --dev oxfmt
```

</Tab>

<Tab value="npm">

```bash title="Terminal"
npm install --save-dev oxfmt
```

</Tab>

<Tab value="bun">

```bash title="Terminal"
bun add --dev oxfmt
```

</Tab>
</PackageManagerTabs>

### 스크립트 만들기

`package.json` 루트에 서식 지정 스크립트를 추가합니다.

```json title="./package.json"
{
  "scripts": {
    "format": "oxfmt --check",
    "format:fix": "oxfmt ."
  }
}
```

### 루트 작업 생성

Turborepo에 스크립트를 등록합니다.

```json title="./turbo.json"
{
  "tasks": {
    "//#format": {},
    "//#format:fix": {
      "cache": false
    }
  }
}
```

이제 `turbo run format`을 실행하여 형식을 확인하고 `turbo run format:fix`을 실행하여 코드 형식을 지정할 수 있습니다.

## oxlint와 oxfmt를 함께 사용하기

두 도구를 모두 사용하는 리포지토리의 경우 통합된 품질 작업으로 이를 조정할 수 있습니다.

```json title="./package.json"
{
  "scripts": {
    "lint": "oxlint .",
    "lint:fix": "oxlint --fix .",
    "format": "oxfmt --check",
    "format:fix": "oxfmt ."
  }
}
```

```json title="./turbo.json"
{
  "tasks": {
    "//#quality": {
      "dependsOn": ["//#lint", "//#format"]
    },
    "//#quality:fix": {
      "dependsOn": ["//#lint:fix", "//#format:fix"]
    },
    "//#lint": {},
    "//#lint:fix": {
      "cache": false
    },
    "//#format": {},
    "//#format:fix": {
      "dependsOn": ["//#lint:fix"],
      "cache": false
    }
  }
}
```

이 구성을 사용하면 다음과 같습니다.

- `turbo run quality`을 실행하여 Linting과 서식을 동시에 확인합니다(둘 다 파일을 수정하지 않으므로 안전함).
- `turbo run quality:fix`을 실행하여 Linting 및 서식 문제를 모두 해결합니다. Lint 수정 후 서식을 실행하여 파일 쓰기 경쟁 조건을 방지합니다.

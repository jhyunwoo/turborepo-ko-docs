Turborepo는 실행할 스크립트와 작업을 찾기 위해 JavaScript 생태계의 규칙을 기반으로 구축되었지만 해당 스크립트가 수행하는 작업은 신경 쓰지 않습니다. [JavaScript 작업공간에서 패키지를 지정하기 위한 지침](/docs/crafting-your-repository/structuring-a-repository#specifying-packages-in-a-monorepo)에 따라 Turborepo에 다른 언어나 도구 체인을 추가할 수 있습니다.

예를 들어 저장소의 `./cli` 디렉터리에 Rust 프로젝트가 있을 수 있습니다. 이 디렉터리를 JavaScript 패키지 관리자의 작업 영역에 패키지로 추가하려면 해당 디렉터리를 작업 영역 정의에 추가하세요.

그런 다음 `package.json`을 디렉터리에 추가합니다.

```json title="./cli/package.json"
{
  "name": "@repo/rust-cli",
  "scripts": {
    "build": "cargo build --release"
  }
}
```

이제 `turbo build`을 사용하면 `./cli/package.json`의 `"build"` 스크립트가 `turbo`이 실행하는 작업에 포함됩니다.

## 빌드 아티팩트 캐싱

`turbo.json`의 [출력 키](/docs/reference/configuration#outputs)를 사용하여 빌드의 출력이 캐시되고 있는지 확인하세요. Rust CLI가 카고로 컴파일되는 경우 릴리스 빌드는 `target/release` 디렉터리에 생성되며 다음을 사용하여 이를 캐시할 수 있습니다.

```json title="./turbo.json"
{
  "tasks": {
    "build": {
      "outputs": ["target/release/**"] // [!code highlight]
    }
  }
}
```

## 종속 관계 만들기

디렉터리는 이제 패키지 관리자 작업 영역의 일부이므로 JavaScript 패키지와 정확히 동일한 종속성을 생성할 수 있습니다.

예를 들어, 위의 `rust-cli` "패키지"가 `web` 애플리케이션보다 먼저 빌드되었는지 확인하려면 이를 `web` 애플리케이션의 종속성에 설치하세요.

  <Tab value="pnpm">

```diff title="./web/package.json"
{
  "devDependencies": {
+   "@repo/rust-cli": "workspace:*"
  }
}
```

  </Tab>

  <Tab value="yarn">

```diff title="./web/package.json"
{
  "devDependencies": {
+   "@repo/rust-cli": "*"
  }
}
```

  </Tab>

  <Tab value="npm">

```diff title="./web/package.json"
{
  "devDependencies": {
+   "@repo/rust-cli": "*"
  }
}
```

  </Tab>

  <Tab value="bun">

```diff title="./web/package.json"
{
  "devDependencies": {
+   "@repo/rust-cli": "workspace:*"
  }
}
```

  </Tab>
</PackageManagerTabs>

다음과 같은 `build` 작업과 함께 `turbo.json`이 주어지면:

```json title="./turbo.json"
{
  "tasks": {
    "build": {
      "dependsOn": ["^build"],
      "outputs": ["dist/**", "target/release/**"]
    }
  }
}
```

`turbo build`은 먼저 Rust CLI용 아티팩트를 생성한 다음 `web` 애플리케이션을 빌드합니다.

## 이 오류가 발생한 이유

루트 작업은 모노레포의 루트 `package.json`에 정의된 스크립트입니다. 이러한 작업은 종종 `turbo`이라고 합니다. 예를 들어:

```json title="./package.json"
{
  "scripts": {
    "build": "turbo run build"
  }
}
```

이로 인해 [토폴로지 종속성](/docs/reference/configuration#dependson)을 선언할 때 문제가 발생합니다. 토폴로지
종속성은 패키지가 자체 작업을 실행하기 전에 패키지의 종속성이 해당 작업을 실행해야 함을 지정합니다.

```json title="./turbo.json"
{
  "tasks": {
    "build": {
      "dependsOn": ["^build"]
    }
  }
}
```

루트 패키지는 작업 영역 내부의 모든 패키지에 대한 종속성이므로 해당 작업이 먼저 실행됩니다.
그러나 해당 작업이 `turbo`을 호출하므로 이로 인해 무한 루프가 발생합니다.

## 솔루션

루트 작업이 `turbo`을 호출하지 _않는 한_ `turbo.json`의 `tasks` 필드에 추가할 수 있습니다.

```json title="./turbo.json"
{
  "tasks": {
    "//#build": {}
  }
}
```

이렇게 하면 작업이 `//#build`에 종속되도록 허용됩니다.

그러나 루트 작업이 `turbo`을 호출하면 무한 재귀가 발생할 수 있습니다. 이 경우에는 다음을 따르지 않는 것이 좋습니다.
루트 작업에. 대신 이 루트 작업이 의존하는 작업을 확인하고 해당 작업에 직접 의존할 수 있습니다.
예를 들어 `//#build`이 `app#lint` 및 `docs#lint`에 종속되는 경우 이를 종속성으로 선언할 수 있습니다.

## 이 오류가 발생한 이유

`turbo.json`에서 환경 변수를 선언할 때 `$` 접두사를 붙일 수 없습니다. 이
Turborepo 1.5에서 더 이상 사용되지 않는 환경 변수에 대한 종속성을 선언하기 위한 이전 구문이었습니다.

```json title="./turbo.json"
{
  "globalEnv": ["$MY_ENV_VAR"]
}
```

위에서 선언한 환경 변수에는 `$` 접두사가 있습니다.

## 솔루션

환경 변수 선언에서 `$` 접두사를 제거합니다.

```json title="./turbo.json"
{
  "globalEnv": ["MY_ENV_VAR"]
}
```

`npx @turbo/codemod migrate-env-var-dependencies`을 사용하여 `env` 및 `globalEnv` 키로 마이그레이션할 수 있습니다.
[자세한 내용은 codemod 문서](/docs/reference/turbo-codemod#turborepo-1x)를 확인하세요.
